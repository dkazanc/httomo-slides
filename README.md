# HTTomo presentation material

HTTomo workshop slides built with the [Quarto RevealJS](https://quarto.org/docs/presentations/revealjs/) presentation format.

## Useful links

- [HTTomo GitHub repository](https://github.com/DiamondLightSource/httomo)
- [HTTomo Documentation](https://diamondlightsource.github.io/httomo/)

### Render the slides

1. Install [Quarto](https://quarto.org/docs/get-started/).
2. Clone this repository.
3. Run `quarto preview` for a local preview.
4. Run `quarto publish gh-pages` to publish to GitHub Pages.
